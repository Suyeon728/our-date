장소 저장: 직접 이름/종류/지역/주소/메모 등록 또는 추천 결과에서 저장. 좌표 있는 장소는 15km 이내 후보, 좌표 없는 장소는 선택 지역 기준으로 우선 표시. 직접 추가한 장소의 주소는 지도 검색용이며 좌표 자동 검증은 하지 않습니다. 브라우저별 localStorage 사용, 백업 내보내기/불러오기로 다른 기기에서 이전 가능. 서버 동기화 없음. 브라우저 데이터 삭제 시 백업 없이 복구 불가.

기존 무료 API 사용 범위 유지. TourAPI 인증 403과 서울/부산 API 실제 연결은 미검증. 일부 API 실패 시 기존 자료 유지 및 배포 후 오류 표시. 모든 민간 행사, 리뷰 수, 실제 이동/영업시간을 보장하지 않습니다.
