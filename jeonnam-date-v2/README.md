# 우리 둘의 아지트
무료 GitHub Pages용 PWA. 공개 저장소 main 브랜치에 압축 안의 모든 파일(숨김 .github 포함)을 올린다. Settings → Pages → Source: GitHub Actions. Actions → Refresh places and publish → Run workflow. 성공하면 Pages에 표시된 HTTPS 주소를 스마트폰에서 열고 홈 화면에 추가. 매일 한국시간 06:23 자동 실행 예정. 공개 저장소에는 개인 정보나 API 키를 넣지 않는다. 즐겨찾기는 기기별 로컬 저장이며 공유되지 않는다.
직접 새로고침은 선택 지역 OSM 데이터를 브라우저로 가져온다. 초기 DB는 비어 있다. OSM의 한국 장소 등록률과 태그는 제한적이며 실제 신규 개업/폐업이나 맛/인테리어를 확인하지 못한다. DB 최초 발견일만 제공. 음식 검색은 이름/OSM cuisine 태그 부분 일치(영어 태그도 가능). 수집 오류 시 기존 DB 유지. 무료 API 장애 및 GitHub 일정 지연 가능. 60일 저장소 활동 없으면 예약 실행이 중지될 수 있으므로 Actions에서 재활성화. OSM 데이터는 ODbL: https://www.openstreetmap.org/copyright. 배포 전에 실제 API 요청 및 모바일 설치 확인 필요.

## v2
여수시청 근사 좌표 기본, 현재 위치 또는 좌표 변경 가능. 광주 및 전북·경남 일부 지역 추가(전국 전체 아님). OSRM 공개 데모 서버로 후보 상위 8개를 검사하며 각 방문지까지 편도 제한을 적용한다. 실시간 교통 및 왕복 시간은 반영하지 않는다. 무료 표시(fee=no) 박물관/미술관/공연장 등만 추가 후보로 사용하며 개별 행사 무료 여부는 보장하지 않는다. 날짜별 무료 공연/전시/체험 검색 링크 제공. 실제 행사 일정 자동 수집은 미구현이며 문화포털 API 키 발급 및 별도 연동 필요. 공개 경로 서버 가용성 및 브라우저 CORS에 따라 실패할 수 있다. 실제 위치를 외부 경로 서버에 전송한다. 초기 DB는 비어 있음.
